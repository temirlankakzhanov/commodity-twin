    Optimal flows

    A linear programme (HiGHS via SciPy) sets the flow on each sea lane to maximise total margin within supply, demand and chokepoint capacity.

    Volumes, freight and capacities are assumptions.

        Under the hood

        Open source, tested, three commands to run.

        tests pass

        Counted from the pytest run that built this page's data.

        • Optimiser sends each cargo down the most profitable open lane (a linear programme on an illustrative network).
        • Monitor flags sudden drops in IMF PortWatch transit calls against a lagged baseline.
        • Validation backtests five VaR/ES models with Kupiec, conditional-coverage, Basel and ES tests.

        Limits & sources

        Limits

        • The trade network is illustrative: volumes, freight and capacities are assumptions. Scenarios are not a forecast.
        • The VaR/ES backtest is a model test on a plan-implied book, not a trading record.
        • The traffic monitor is a change detector: it flags sudden drops and goes quiet during a sustained closure.

        Data as of the snapshot dates.
